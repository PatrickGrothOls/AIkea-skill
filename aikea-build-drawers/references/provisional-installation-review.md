# Provisional drawer installation review

A requested design review may include a complete proposed drawer installation
while physical qualification remains open. This is an explicit presentation
stage, not completion of the drawer contract or permission to machine parts.
Continue sourcing and qualification alongside it; never use this stage to drop
requested drawers or close their outstanding work.

## Required contents and evidence

- Preserve the exact selected runner size and verified source solids on both
  hands. Include the captured-bottom box, structural front, compact supports,
  companion parts and both attachment interfaces in the same assembly tree.
- Derive all dimensions from this project's actual opening, selected source
  hardware and documented installation dimensions. Do not copy a previous
  project's widths, scale purchased hardware or treat an illustrative hinge
  pose as a known moving envelope.
- Apply source-backed mounting axes and justified operations together with the
  joinery. Separate a documented design assumption from a manufacturer dimension.
  Unknown pilot diameter/depth remains an unsatisfied machining requirement;
  do not invent a cut to make the model look drilled. A nominal screw candidate
  is not an approved fastening specification.
- Check actual closed geometry, hardware placement, front/runner interference,
  support attachments and available machining faces. For unresolved movement,
  save exactly which poses/clearances are assumed, what was checked, and what is
  unknown. Do not create a fabricated full-travel PASS record.
- Show one complete proposed installation first. Repeating it for layout review
  is allowed only after actual closed-fit checks; copied qualification gaps must
  remain attached to every affected drawer. The requested count, modeled count,
  fully qualified count and missing operations are separate facts.

## Export boundary

Use the actual construction GLB emitted by
`aikea-design-furniture/scripts/build_furniture_design.py` for a clearly titled
“Provisional design — fixings/movement unqualified” view. Retain failed/pending
reports next to the artifact and include qualifications in the screenshot
caption. A diagnostic view must not be relabelled as a complete-review pass.
The normal complete-review and fabrication gates remain unchanged: missing or
stale travel, fastening or machining evidence still blocks completed delivery.
Do not patch those gates, remove requirements or export this candidate as a
CNC-ready package. An open-door illustration must identify missing hinge motion.

This exception permits inspecting an actual proposed installation, not a bare
box, a floating rail, an imagined fixing pattern or unsupported fabrication.
