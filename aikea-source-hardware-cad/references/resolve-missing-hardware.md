# Resolve missing hardware without dropping furniture features

A missing library entry is a sourcing or implementation task. It is not evidence
that the requested drawer, hinge or other feature is impossible. Preserve the
requested count, owning assembly and constraints in the active project plan.

## Find a usable input

1. Establish the actual clear opening, material, depth, intended travel/load and
   door/hinge obstructions. Preserve an explicitly chosen product. Otherwise,
   search exact compatible sizes using official manufacturer sources; a locally
   registered 500 mm runner does not force a 500 mm drawer or a deeper cabinet.
2. Inspect both the official installation drawing and CAD download route. Keep
   nominal length, minimum body depth, hands, accessories, fixing requirements
   and source URLs together. Recheck companion parts: a long spacer does not
   automatically become suitable when a shorter runner is selected.
3. Use available download tools, including the manufacturer's visible browser
   flow. Inspect the current session before assuming registration is required.
   An empty format list or a pending CAD generation is not a login blocker.
   Wait for the generated file, download it and verify it actually reached disk;
   clicking Download alone does not establish retrieval.
4. A direct-download error does not prove the normal browser download fails. Use
   the supported browser route if available; never bypass access controls. If a
   different neutral format is available, assess a verified conversion separately.
   A DXF archive is not a STEP file, and renamed or scaled geometry is not exact CAD.

## When the user must act

Prepare everything that can be done first. If the live portal actually requires a
personal login, agreement or inaccessible download, give the exact configured
product link and one concrete next action. With browser access, open it; without
browser access, provide the link. Include screenshots of the observed controls
when possible, explain the requested format and where to return the file. Never
invent screenshots or report an untested portal as requiring registration.

Save the exact blocker, attempted route, required file, destination and next
command in the active plan. Continue independent preparation. Resume the owning
builder when the input arrives; the user should not need to restate the design.

## Continue through installation

Store unchanged CAD and provenance with `store_hardware_cad.py`. Import and check
identity, units, solids and native bounds. Source success hands work back to the
construction skill; it does not close the furniture task.

If the exact size is not implemented, adapt the shared hardware profile and
installation under the repository's normal development workflow. Verify one
complete drawer with both runners, actual host/drawer fixings, necessary spacers,
chosen CNC faces and movement before repetition. Do not stretch an existing
product model or copy another length's fixing coordinates.

Retain unresolved material/fastener or manufacturing checks explicitly, with a
specific way to resolve each one. Do not silently reduce feature count, deliver
an unmachined box, or call the project complete because a partial viewer works.
