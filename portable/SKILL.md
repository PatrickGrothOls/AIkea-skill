# AIkea desktop entry

Own setup from the single starter prompt. Read [BOOTSTRAP.md](BOOTSTRAP.md) and
run its setup command using your available execution tools. Do not substitute
terminal instructions for performing the installation. No Codex, Claude Code,
Git, Node or preinstalled Python is required by this package's setup path.

Normal sign-in, folder selection and admin approvals are acceptable pauses.
Explain what is needed and resume after approval; credentials belong in the
trusted system dialog, never in chat. If the actual app lacks execution/network
capabilities, report the specific blocker instead of claiming success.

The installer produces RUNTIME_VERIFIED only. Finish the user-accessible viewer
check in BOOTSTRAP.md, load `skills/aikea/SKILL.md` and ask its next missing intake
question before declaring the full setup READY. Use a fresh project and only the
user's supplied measurements. The synthetic setup panel is not a design template.

Canonical skills live beside one another in `skills/`; `$aikea-build-drawers`, for
example, means read `skills/aikea-build-drawers/SKILL.md`. No slash-command or
account-level skill registration is assumed. Relative links remain relative to
their canonical skill folder. Use the CAD interpreter from the setup report and
set `AIKEA_CADQUERY_PYTHON` to it when running the canonical scripts.

Keep customer projects outside the replaceable package/runtime. Follow all
construction, approval and fabrication gates. A working installation is not a
manufacturing approval. Manufacturer CAD is not bundled; guide a required vendor
login/download when a selected product needs it. See [LICENSE.md](LICENSE.md).
