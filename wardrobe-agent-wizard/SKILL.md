# WardrobeAgentWizard

Load the [furniture workflow](../aikea/SKILL.md) and perform its next checked
stage. It owns the session's version check, measurement intake and construction
requirements. Use only measurements supplied for the active project.

The sibling `aikea*` folders are retained implementation names for compatibility.
Present the product to the user as WardrobeAgentWizard.
