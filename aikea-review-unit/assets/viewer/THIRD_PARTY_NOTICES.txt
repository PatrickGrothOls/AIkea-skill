Complete copyright and license notices for the bundled JavaScript dependencies
are included in THIRD_PARTY_LICENSES.md beside this file. The production build
regenerates that file from the dependencies actually included in the viewer.
SUPPLEMENTAL_LICENSES.md supplies the notices omitted from published dependency
archives and documents their sources.

The AIkea unit review viewer bundles React, React DOM, Three.js,
@react-three/fiber, @react-three/drei, @react-three/postprocessing,
@react-three/gpu-pathtracer, postprocessing, n8ao, and three-gpu-pathtracer.
These projects retain their respective licenses. The generated file includes
the license text shipped by each package, including postprocessing's Zlib terms
and n8ao's CC0 text (its package metadata separately labels the license ISC).
