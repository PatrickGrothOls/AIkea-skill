   no fictional cabinet counts or new purpose registry are needed for custom work.

   standard configurator's review sequence.

   its geometry. Document the minimal absent-file metadata mapping before evidence
   is built, without overwriting existing YAML or inventing wardrobe fields.

   authored-parent generic review path explicit. Linked lighting's inclusion

   by appearance/name. These edits correct discoverability, not construction policy.

   multi-part hosts retain their current-face planner and generic full-tree review
   without requiring a fictional wardrobe run or grid.
