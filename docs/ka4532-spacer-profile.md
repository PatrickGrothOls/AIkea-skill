## Current state

The exact project-local STEP set now loads through checksum-gated public
metadata. The four runner solids are classified by source geometry, the same
unchanged article 13952 solid is retained for both sides, and both side
placements resolve from the cabinet parts' saved local faces. The right spacer
uses a rigid right-handed reorientation; no geometry is mirrored, scaled, or
substituted. The proof compares every rendered purchased solid with its
independently reloaded checksum-gated STEP selector by full solid overlap, so an
equal-volume generated substitute fails. Every proof attempt also invalidates
older evidence before CadQuery runtime handoff. Combined runner-and-spacer panel
reservations and recursive closed, open, and removed review behavior are
implemented and tested. The promoted first cabinet now has checksum-linked
closed/open GLBs and a saved proof showing the complete drawer subtree and both
moving runner members travel 500 mm, both exact spacers and fixed members stay in
the cabinet, both endpoints have no unintended collision pairs, and the
conservative linear swept envelopes report no conflict.

The complete-cabinet and fabrication gates remain closed. Neither the promoted
proof nor Hettich's available product data defines one approved
spacer-to-cabinet fixing subset, fastener identity, pilot diameter, or pilot
depth. Those values will not be inferred from candidate holes in the exact STEP.
The current proof cabinet's 741 mm fitted door also exceeds its selected Riex
profile's 600 mm limit. Repetition remains disabled until both blockers are
resolved and the complete cabinet passes independently.

The drawer skill now treats KA 4532 plus article 13952 as the default when a
client requests verified Hettich runners without naming a product. KA 5332
remains available only for an existing project or an explicit client choice.
