# Korrekt plate machining

Use this construction capability for a selected Hettich 61854 screw-on plate
supporting the 70151 foot. It does not choose support spacing or replace an
existing wooden base automatically. First establish the deck and leg layout.

## One placement for the plate, footprint and negative

`KorrektMountingProfile` retains the exact article identities, the measured
95.00248 × 80 mm conservative rectangular plate envelope, the offset socket axis,
and four 64 × 64 mm screw centres. The negative owns four Ø3 mm through pilots
and one Ø8 mm adjustment passage. All are cut from the deck's top side through
its actual thickness, with 1 mm cutter overshoot at both ends.

The envelope encloses the whole plate. It is deliberately conservative at the
rounded corners; it is not a detailed rendering or a structural bearing model.
The profile uses the untouched 61854 source frame: z=0 contacts the deck underside,
and the native socket axis is (-0.0475, -0.0631) mm. Use
`KorrektMountingCutter.placement(axis_xy_mm, bottom_z_mm, rotation_deg)` when
creating the plate's declared placement from a chosen leg axis. The machining
reads that same purchased-hardware placement, including its rotation.

Detailed vendor CAD is not required at run time for this measured profile. Keep
an exact `PurchasedHardwareSpec` for each plate and foot even if the preview uses
a labelled simplified shape or `BuiltPurchasedHardware(spec, None)`. Existing
source and fit verification remain necessary when changing to another article.

## Apply to an authored base

After building panel blanks and their joining cuts, before any other operation
duplicates these mounting bores, call:

```python
from korrekt_mounting_machining import KorrektMountingMachining

built = KorrektMountingMachining().apply(
    built,
    deck_part_ids=deck_part_ids,
    plate_hardware_ids=plate_hardware_ids,
    minimum_edge_margin_mm=confirmed_margin_mm,
)
```

The IDs must already exist in the assembly. Pass all supporting deck segments,
not kickboards, cabinet floors or unrelated panels. The plates must be Hettich
61854 and contact the horizontal deck underside. Supporting panels must share
their upper/lower levels. The margin is an explicit project value, not a hidden
manufacturer recommendation.

The builder unions the declared panel outlines for the edge check so internal
module seams disappear. It checks the entire rotated plate envelope for overhang
and measures its nearest distance to outside edges and outline cutouts. An
invalid location fails with the measured/required clearance before returning a
machined assembly. This checks the declared outlines, not load capacity or the
bearing effect of face recesses; review those separately.

The sourced pattern is generated by the shared `SurfaceHolePattern`. One negative
is transformed into every intersecting deck part using the same
`PartCut` contract as Cabineo. Half-lap participants receive complementary portions
of the through-holes. The common `PanelMachiningFeature` executes and independently validates the cuts,
preserving unrelated parts, local operations, child assemblies and purchases.
Joints retain plate identity, measured clearance and the required margin. The
builder checks total removed volume, rejecting duplicate
machining, missing material and overlapping unjoined blanks.

Keep the adjustment route through any cabinet floor above the deck as a separate
aligned operation; the mounting negative machines only the named deck panels.
For finishing, permanently close pilot holes only at their top ends, sand flush
and paint, retaining screw engagement below. Keep adjustment passages accessible.

## Evidence and limits

- Plate pattern and envelope measured from 61854 STEP SHA-256
  `6b70098fc67bf09f6e3ac9006e10118b01391384e7116e759cd8a08454977e34`.
- [Hettich plate drawing](https://catalog.hettich.com/General/TuI/en_DE/catalogs/TuI_en_DE/pdf/save/bk_1361.pdf): Ø4 × 35 mm screws.
- [Furnica MDF guidance](https://furnica.co.uk/blogs/guides/how-screw-mdf-pre-drilling-wood-screws): Ø3 mm pilot for a typical Ø4 mm wood screw; follow a chosen screw's specific instructions when they differ.
- Ø8 mm adjustment access is the current design choice; physical drive clearance,
  screw engagement, permanent filler depth and deck support still need workshop
  checks. A passing negative/edge test does not approve a full installation.

Never subtract the visual leg/plate body to infer woodworking holes. The plate's
own Ø6 mm screw wells are not the MDF pilot diameter.

## Shared construction status

This is a sourced component operation using the shared joint-feature boundary.
It is not added as a automatically qualified built-in: the fabrication gate still
requires current registered feature evidence for these mounting joints, including
exact affected panels and plate/foot purchase IDs. Keep the physical-fit, screw,
filler and access checks unresolved until their evidence exists. A useful negative
and an inventory-visible purchase do not settle those installation requirements.

## Owned component composition

Use `KorrektComponentFeature(deck_part_ids, stations, minimum_edge_margin_mm)`
with explicit `KorrektStation(plate, foot)` pairs of PurchasedHardwareSpec values.
Exact assets are `hettich_korrekt_61854` and `hettich_korrekt_70151`; placements are
in the owning assembly frame and preserve the native source CAD frames. The model
selects the layout against the design's support and access requirements.

Save the feature as the local module's `FEATURE`, include it in the existing
ordered feature builder, then call `feature.register(project_root, built)` to
register the resulting participant scope. This registration provides no approval.
The common fabrication gate still requires current, scoped evidence and the
physical installation checks. Load CAD from `hardware/hettich/korrekt/<article>/
source/<article>.stp`; the generic viewer verifies the registered bytes.

To remove the component, remove its manifest entry and rebuild from the base.
The omitted feature then owns no cuts, purchases or requirements. Remove its
obsolete report as part of the edit; never reuse that report after a layout change.

Each article is one installed purchased piece, separate from supplier pack size.
Absent purchase metadata gets this explicit one-piece identity; an existing valid
fastener-inclusion choice is retained. The ordinary physical counter therefore
reports one plate and one foot per station. The inherited default includes
mounting fasteners per the project's purchasing assumption; set
`mounting_fasteners_included=False` when separate screws must be sourced.
